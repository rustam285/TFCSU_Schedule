# Для копирования 10 — экспорт расписания за период + пакетный импорт заочников и очно-заочников

## Что добавляется

1. **Экспорт полного расписания за период.** На гостевых страницах (по группам всех
   трёх форм обучения, по преподавателям, по аудиториям) под кнопками «Скачать:
   Word / Excel / PDF» появляется сворачиваемое меню «Полное расписание за период
   (с заменами)»: даты «с — по» (предзаполняются выбранным на странице диапазоном)
   и те же три кнопки. В документ попадает всё, что видно на странице за период —
   постоянное расписание И замены, развёрнутые по датам. Дни — секциями
   («Понедельник, 05.10.2026»), документ может занимать несколько страниц.
   Интервал — не больше 30 дней, как у просмотра. Прежние три кнопки (сетка
   семестра) остаются без изменений.
   Для заочной и очно-заочной форм это первый содержательный экспорт: их
   расписание хранится по датам, и семестровый бланк по недельной сетке был пустым.
2. **Пакетная (мультифайловая) загрузка расписания заочников.** Страница
   «Импорт (заочная форма)» теперь принимает сразу несколько .xlsx: слева список
   записей (файл с теми же группами перезаписывает запись), справа сетка по датам —
   дату или пару можно добавить/убрать вручную. «Загрузить» сохраняет все записи
   разом: безошибочные уходят в базу (расписание групп записи перезаписывается
   ПОЛНОСТЬЮ), ошибочные остаются в списке с подсветкой красным.
3. **Пакетная загрузка очно-заочников.** Страница «Импорт (очно-заочная форма)» —
   та же недельная сетка 2×7×8, что и раньше, но файлов можно несколько и у каждой
   записи в списке свой интервал дат (плюс общий «интервал по умолчанию» для
   новых файлов — в самих файлах дат нет). При сохранении внутри интервала записи
   старое расписание групп удаляется и пары сетки «разворачиваются» на подходящие
   даты интервала; даты вне интервала не трогаются.
4. **Многостраничные файлы по листам.** Парсер разбирает все листы книги: каждый
   лист становится отдельной записью и подписывается своим названием. Если лист
   назван диапазоном дат («01.09-27.09.26»), интервал записи заполняется
   автоматически из названия; листы без дат (например, «Лист1») — интервал
   «по умолчанию» или вручную. Работает и на очных страницах ВО/СПО (многостраничные
   файлы больше не теряют листы). Из названий дисциплин парсер вырезает группы
   в скобках с датами («(02.10.26 - лекция/ 16.10.26 - пз)») — раньше такие
   названия не находились в справочнике.

## Установка на сервер

1. Остановить сайт: `schtasks /End /TN "TFCSU_Schedule_Site"` (или закрыть окно).
2. Скопировать файлы из этой папки поверх проекта **с сохранением структуры
   каталогов**. `db.sqlite3` не трогаем. Удалить два старых JS-файла (список выше).
3. Пересобрать статику и запустить сайт:

   ```
   .venv\Scripts\python.exe -m django collectstatic --settings=djangoProject.settings --noinput
   schtasks /Run /TN "TFCSU_Schedule_Site"
   ```

**Важно:** после collectstatic обязателен перезапуск сайта (whitenoise кэширует
статику в памяти процесса — иначе страницы будут отдавать старые JS).
**Парсер тоже изменился — перезапустить и его** (его окно закрывали на шаге 1;
`schedule-parser\install.bat` НЕ нужен, зависимости те же).
`pip` и `migrate` НЕ требуются. Задачи планировщика не меняются.

## Проверка после установки

- Гостевая страница «Расписание по группе» → выбрать заочную группу, период с
  занятиями → под кнопками «Скачать» раскрыть «Полное расписание за период» →
  скачать PDF: внутри заголовок «с ДД.ММ.ГГГГ по ДД.ММ.ГГГГ», дни с парами.
- Попытка выгрузить период длиннее 30 дней — понятная ошибка «Слишком большой
  интервал».
- Импорт заочной формы: выбрать сразу 2–3 файла → в списке появились записи,
  у каждой даты и пары → «Загрузить» → сводка «Расписание загружено для групп …».
- Импорт очно-заочной формы: многостраничный файл (листы вида «01.09-27.09.26»)
  → в списке появились отдельные записи по листам с датами из названий;
  одностраничный файл без дат в названии листа → интервал «по умолчанию»/ручной.
- Запись с ошибкой (несуществующая дисциплина в ячейке) не сохраняется, ячейка
  подсвечена красным, остальные записи загружаются.
