# Расписание учебных занятий

1. Устанавливаешь питон* - *ИДЕ использовался пайчарм комм. ед.*,  
2. Запускаешь батник "запуск_локально.bat" - *он устанавливает все нужные либы(если еще не установлены) и запускает проект локально*,
3. Запуск лок. сервер через терминал `python manage.py runserver` - *команду также можно посмотреть в том же батнике*,
4. Смотришь сайт через юрл, выводящийся в терминале + юрлки из мейн приложения.
* Если нужно, заходишь на бд админку через `"ссылка"/admin-panel/`

**устанавливаешь корректно, т.е. чтобы в изменении переменной среды в PATH был адрес питона*

Если при запуске батника, ничего не происходит, значит пробуй запустить команду в повершеле без добавления python,
т.е. просто `./manage.py runserver`, этот способ у меня работает на рабочем пк в ТСО, а исходный способ на домашнем ноуте

Для миграций:
`python .\manage.py makemigrations`
`python .\manage.py migrate`

## Локальное окружение (venv)

Рядом с проектом лежит `.venv` (python 3.13, все зависимости из requirements.txt):

```
.venv\Scripts\python manage.py runserver
```

## Настройки прода

`DEBUG`, `SECRET_KEY` и `ALLOWED_HOSTS` берутся из переменных окружения
(`DJANGO_DEBUG`, `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`). Локально ничего
задавать не нужно. Подробности — в [DEPLOY.md](DEPLOY.md).

## Резервные копии базы

- Автоматически перед каждым импортом расписания, вручную из админки
  («Резервные копии») или командой `python manage.py backup_db`.
- Ежедневный бэкап по расписанию — `backup_daily.bat` + инструкция в [DEPLOY.md](DEPLOY.md).
- Правила отображения дисциплин в расписании преподавателя — кнопка
  «Правила предметов» в админке.
