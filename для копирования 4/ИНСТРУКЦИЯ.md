# Обновление «для копирования 4»: система настраиваемых уведомлений

## Что добавляется

**Уведомления о парах для залогиненных пользователей** (гостям недоступны):

- в шапке сайта рядом с «Выйти» появляется **колокольчик** с бейджем-счётчиком;
- по клику открывается **шторка справа**: уведомления на текущую неделю — с сегодня
  до воскресенья (если сегодня воскресенье — следующая неделя). Сгруппированы по датам
  («Сегодня…», «Завтра…», день недели), внутри — преподаватель/аудитория и их пары
  (номер, время, дисциплина, ауд./группа);
- **настройка уведомлений**: кнопка «Уведомления» на главной админки (карточка
  «Сервис») и пункт в бургер-меню (секция «Сервис»);
- настройка отдельная для **преподавателей** и для **аудиторий**: выбор из списка
  (с поиском и пагинацией) → настройка конкретного преподавателя/аудитории;
- три режима (действует один):
  - **«По умолчанию»** — уведомлять, только если сегодня или завтра есть пары;
  - **«Конкретные даты»** — добавляются любые даты, уведомление только в них;
  - **«Дни недели»** — галочки в сетке 7 дней × 2 недели (отдельно 1-я и 2-я неделя).
  Добавление даты автоматически включает режим дат, сохранение дней недели —
  режим дней (в сообщении после сохранения это видно); радио-кнопкой режим
  можно задать и явно.
- одна и та же дисциплина (тот же формат и преподаватель), идущая в один слот
  у нескольких групп, показывается **одной парой** — группы перечисляются
  через запятую;
- в любом режиме уведомление появляется, только если в этот день реально есть пара
  (учитываются и постоянное расписание, и замены на дату; для преподавателя
  применяются его правила отображения дисциплин).

Уведомления вычисляются при открытии шторки — фоновые задачи не нужны.
У каждого пользователя свои подписки.

## Порядок установки на сервере

1. Останови сайт (закрой окно `запуск_сервера.bat`).
2. Сделай запасную копию проекта и файла `db.sqlite3`.
3. Скопируй файлы из папки поверх проекта.
4. **Применить миграцию** (создаёт таблицу подписок) — в корне проекта:

   ```
   .venv\Scripts\python.exe -m django migrate main --settings=djangoProject.settings
   ```

5. `pip install` не нужен, `collectstatic` не нужен (стили шторки — внутри base.html).
6. Запусти сайт снова.
7. Проверка: зайди под любым логином — в шапке справа колокольчик; на главной
   админки и в бургер-меню есть «Уведомления»; настрой подписку на преподавателя
   в режиме «Конкретные даты» на день с парами — уведомление появится в шторке.

## Если что-то пошло не так

- **Ошибка «no such table main_notificationsubscription»** — пропущен шаг 4 (migrate).
- **Колокольчик не появился** — не скопирован `base.html` или пользователь не залогинен
  (гостям колокольчик не показывается намеренно).
- Откат: вернуть прежние версии 4 изменённых файлов, удалить новые файлы из таблицы
  выше и выполнить `.venv\Scripts\python.exe -m django migrate main 0026
  --settings=djangoProject.settings` (откат миграции), затем перезапустить сайт.

## Как это устроено (для будущих правок)

- Модель: `NotificationSubscription` (`main/models.py`) — user, преподаватель
  ИЛИ аудитория, режим, даты и дни недели в JSON-полях.
- Логика: `main/services/notification_service.py` — диапазон недели (вс → следующая
  неделя), триггеры режимов, сбор уведомлений на основе тех же запросов, что и
  страницы просмотра расписания.
- Страницы: `main/views/notification_views.py`; JSON для шторки — `/notifications/data/`.
- Шторка и колокольчик: инлайн-скрипт в `base.html` (зеркало левого меню
  администратора, панели закрывают друг друга).
