# Обновление «для копирования 3»: экспорт расписания в Word / Excel / PDF

## Что добавляется

На трёх страницах просмотра расписания появятся кнопки **«Скачать: Word / Excel / PDF»**:

- «Просмотр расписания по группе» (все три формы обучения: очная, очно-заочная, заочная);
- «Просмотр расписания по преподавателям»;
- «Просмотр расписания по аудиториям».

Кнопки появляются **под таблицей** после нажатия «Показать расписание» и доступны
**всем пользователям, включая гостей** — без входа на сайт.

## Как выглядит экспортируемый файл

Вверху — заголовок из двух строк: кого расписание и семестр, например
«Расписание группы ТФИ-401 (очная форма обучения)» / «1 семестр 2026-2027
учебного года» (семестр и год определяются автоматически по текущей дате).
Дальше — сетка «дни × пары»: названия дней вертикально слева, недели 1 и 2 —
рядом («ТФИ-401, 1 неделя» | № ауд. | «ТФИ-401, 2 неделя» | № ауд.).
С понедельника по пятницу выводятся пары 1–6, у субботы — 1–5 (6-й пары нет;
если в базе появится занятие 6-й пары или позже — строка добавится сама).
Шрифт Times New Roman, во всех форматах книжная ориентация A4.

**Word и PDF всегда умещаются ровно на одну страницу.** В PDF таблица при
необходимости целиком уменьшается (как «вписать лист» в Excel), в Word
автоматически подбирается размер шрифта (от 9 до 4,5 pt) и фиксируется
высота строк — таблица не переносится на вторую страницу.

Имена файлов: **«ТФИ-201_26-27.xlsx»** (группа + учебный год).
Для преподавателей: «Преподаватель_Фамилия_И.О._26-27», для аудиторий:
«Аудитория_213_26-27».

Важно: в файл входит **постоянное расписание семестра**. Разовые замены
на конкретные даты не включаются — они отображаются только на сайте.

Отличия для преподавателя и аудитории: у преподавателя в ячейках —
«Дисциплина (формат), группы», у аудитории сетка из 5 колонок
(«Дисциплина (формат), преподаватель — группы», колонки аудиторий не нужны).
Если в аудитории в одном слоте у нескольких групп одна и та же дисциплина
и преподаватель — группы пишутся одной строкой через запятую.

## Порядок установки на сервере

1. Останови сайт (закрой окно `запуск_сервера.bat`, либо перезапусти службу,
   если сайт крутится как служба).
2. **Сделай запасную копию проекта** (или хотя бы файлов из таблицы выше —
   на случай отката).
3. Скопируй файлы из этой папки поверх проекта согласно таблице.
4. Установи новые библиотеки (в корне проекта):

   ```
   .venv\Scripts\pip install -r requirements.txt
   ```

   Добавились `python-docx` (Word) и `reportlab` (PDF); Excel работает на уже
   имевшемся `openpyxl`. Интернет при установке нужен.
5. Миграции базы **не нужны**. `collectstatic` **не нужен** (стилей и скриптов
   новых нет — кнопки используют уже подключённый Bootstrap).
6. Запусти сайт снова (`запуск_сервера.bat`).
7. Проверка: открой «Просмотр расписания по группе», выбери группу, нажми
   «Показать расписание» — под таблицей появятся кнопки. Скачай файл в каждом
   из трёх форматов и открой: вид должен совпадать с официальным бланком
   (сетка, УТВЕРЖДАЮ, подпись). То же самое на страницах преподавателей
   и аудиторий.

## Если что-то пошло не так

- **Ошибка «не найден системный шрифт с поддержкой кириллицы»** при экспорте в
  PDF — значит, на сервере нет файла `C:\Windows\Fonts\times.ttf` (бывает редко).
  Открой `main\services\export_service.py`, найди список `regular_candidates`
  и допиши туда путь к любому шрифту с кириллицей (`.ttf`), который на сервере есть.
- **Кнопки не появились** — скопированы не все шаблоны либо сайт не перезапущен.
- **Ошибка 500 при скачивании** — смотри консоль сервера; чаще всего это
  «не установлены библиотеки» (шаг 4 пропущен).
- Откат: вернуть прежние версии 5 изменённых файлов и удалить 2 новых
  (`export_service.py`, `export_views.py`), затем перезапустить сайт.

## Как это устроено (для будущих правок)

- Адрес экспорта: `/export/schedule/?type=group|teacher|auditorium&id=<ID>&format=docx|xlsx|pdf`
- Представление: `main/views/export_views.py` — собирает сетку по постоянному
  расписанию; для преподавателя применяются те же правила отображения дисциплин,
  что и на странице просмотра.
- Генерация файлов: `main/services/export_service.py` — сборка сетки
  (`build_grid_for_group/teacher/auditorium`) и три генератора (Excel — openpyxl,
  Word — python-docx, PDF — reportlab). Тексты шапки и подписи, шрифт,
  базовый список пар — в константах в начале файла.
- Семестр и учебный год для заголовка определяет `get_semester_info()`
  (сентябрь-январь — 1 семестр, февраль-август — 2 семестр).
