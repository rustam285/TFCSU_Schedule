# Для копирования 7 — JSON-API для VK-бота

## Что добавляется

Публичные (только GET, без CSRF и авторизации) JSON-эндпоинты для внешних
клиентов — VK-бота и т.п.:

- `GET /api/groups/` — список всех групп:
  `{"groups": [{id, title, form_of_education, form_of_education_label, course, faculty, updated_at}]}`
- `GET /api/schedule/?group_id=<id>&date_from=ГГГГ-ММ-ДД&date_to=ГГГГ-ММ-ДД` —
  расписание группы по датам (постоянное расписание + замены, как на гостевой
  странице `/schedule/group/`). `date_to` по умолчанию равен `date_from`,
  диапазон — не более 31 дня. Ошибки: `{"error": "текст"}` с кодом 400/404.

## Состав

Скопировать с сохранением структуры поверх корня сайта:

```
main/urls.py                              — добавлены маршруты /api/groups/ и /api/schedule/
main/views/api_views.py                   — НОВЫЙ файл: обе JSON-вьюхи
main/services/constant_schedule_service.py — добавлена get_schedule_days_for_api()
```

## Установка

1. Скопировать файлы из этой папки поверх корня сайта (с сохранением структуры).
2. Перезапустить сайт (`запуск_сервера.bat`).

**Не требуется:** pip install, migrate, collectstatic (нет новых моделей,
зависимостей и статики).

## Проверка после установки

В браузере или curl:

```
https://tfcsu.ru/api/groups/
https://tfcsu.ru/api/schedule/?group_id=4&date_from=2026-10-05&date_to=2026-10-11
```

Оба запроса должны возвращать JSON. Требований к пакету «Сообщения сообщества»
нет — API отдаёт данные точно так же, как гостевые страницы сайта.

## Требует

Папок 3–6 (ставятся по порядку; фактически достаточно любой актуальной копии
сайта — меняются только три файла выше).
