# Для копирования 8 — мобильная версия сайта

## Что добавляется

Мобильная компоновка гостевых страниц (главная, расписания по группе/преподавателю/аудитории,
логин) без изменения цветов и без изменения десктопного вида:

- `<meta name="viewport">` в `base.html` — раньше отсутствовал, телефоны показывали
  уменьшенную десктопную версию;
- новый `main/static/css/mobile.css` (подключается последним в `base.html`) — все
  медиа-правила компоновки; палитра не меняется (#6f0724 / #380216 / #dc3545 / #212529);
- на экранах <768px расписание показывается **карточками по дням** (новый компонент
  `components/tables/schedule_cards.html`, тег `render_schedule_cards`); таблица `table.csu`
  остаётся на десктопе без изменений;
- формы фильтров (группа/преподаватель/аудитория + даты + кнопка) на мобиле столбиком,
  селекты select2 и кнопка во всю ширину, даты в две колонки с подписями «С»/«По»;
- на мобиле настройки расписания (табы форм + фильтры + «Вернуться») спрятаны в
  сворачиваемую панель «⚙️ Настройки расписания» — расписание начинается сразу
  под заголовком; на десктопе панель всегда открыта, вид прежний; при ошибке
  фильтра панель автоматически раскрыта;
- табы форм обучения: подсветка активного (тёмная заливка #380216), на мобиле во всю ширину;
- шапка на мобиле в одну строку («ТФ ЧелГУ» слева, «Войти» справа), компактный футер;
- шторка уведомлений и меню администратора не шире экрана на телефонах;
- минимальные защиты админки на телефоне: широкие таблицы (width:1000px) прокручиваются
  внутри страницы, поле живого поиска во всю ширину (без полного редизайна админки).

## Установка на сервер

1. Скопировать файлы из этой папки поверх проекта **с сохранением структуры каталогов**.
2. **Обязательно**: `python manage.py collectstatic` (новый `mobile.css`).
3. **Обязательно**: перезапустить сайт (whitenoise кэширует статику в памяти процесса,
   без перезапуска сайт отдаёт старые файлы).
4. Перезапускать парсер НЕ нужно; `pip install` и `migrate` НЕ требуются.

## Проверка после установки

- На телефоне: главная, `/schedule/group/` (табы, выбор группы, даты, карточки вместо
  таблицы), `/schedule/teacher/`, `/schedule/auditorium/`, `/login/`.
- На десктопе: те же страницы — вид должен остаться прежним (у табов форм обучения
  добавилась только подсветка активного).
